# nailfile Privacy Policy

This repository hosts the public privacy policy for nailfile, available at: https://speedy0697.github.io/nailfile-privacy/

## About

nailfile is an iOS app for nail diary and AI virtual try-on. This privacy policy is required by the App Store and explains how we handle user data.

## Setup

This repository uses GitHub Pages to host the privacy policy at the URL above.

### To update the privacy policy:

1. Edit `index.html` with the new content
2. Commit and push changes
3. GitHub Pages will automatically update within a few minutes

### Repository structure:
- `index.html` - The privacy policy page
- `README.md` - This file
